# SantanderAI Declarative Automation Inspiration

This source note records conceptual inspiration from the public SantanderAI organization at `https://github.com/SantanderAI` for the FCVW declarative automation contract work.

## Inspiration Scope

The FCVW changes credit SantanderAI for architectural ideas only:

- agent-loop and stop-signal concepts inspired by `SantanderAI/ralph`;
- vault/lint and progressive-disclosure maintenance ideas inspired by `SantanderAI/ralph-vault-skill`;
- hard-gate governance concepts inspired by `SantanderAI/mech-gov-framework`;
- guardrail evaluation thinking inspired by `SantanderAI/autoguardrails`.

## Boundary

No SantanderAI source code was copied into FCVW.

The adaptation is Markdown-only and aligned with ADR-0001 and ADR-0002.
