# Syntheses

This directory stores cross-cutting syntheses that combine knowledge from multiple sources.

Examples: post-release consolidations, post-troubleshooting learnings, cross-domain patterns.

## Rules

- Each synthesis must have YAML frontmatter with `type: synthesis`.
- Each synthesis must point to its source documents.
- Syntheses should be created when knowledge from multiple plans, changelogs, or troubleshooting records can be condensed into reusable learning.
