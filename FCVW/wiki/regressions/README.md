# Regression knowledge

Store confirmed, reusable regression records here using `fcvw/regression@1` and `wiki/templates/TEMPLATE_REGRESSION.md`. A record is not a duplicate troubleshooting log: it captures the missing guardrail, permanent prevention, and replay contract after the cause is supported.

The clean template contains no fabricated incident. Create a record only from evidence, update an existing canonical record when the same regression recurs, and link the related plan plus application changelog or framework release.
