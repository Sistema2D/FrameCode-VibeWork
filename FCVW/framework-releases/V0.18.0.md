# FCVW V0.18.0

## Summary

Exact-only identity correction, explainable mandatory routes, complete optional chunks, labeled benchmark, shared graph inventory and continuous source/installation checks.

## Related framework plans

- [Retrieval quality and CI](../Plans/in_progress/P2-R4-2026-09-16-retrieval-quality-and-ci.md).

## Framework surfaces added

Routing, selection, benchmark and archive-verification tools; regression suite; source-only workflow and [CI contract](../governance/CI_CONTRACT.md).

## Framework surfaces changed

Retriever, indexer, graph builders, context/AI/schema/test contracts, inventories and both README entrypoints.

## Framework surfaces removed

None.

## Ownership and path changes

Tools remain framework-owned and install under the contained tools directory. Repository CI stays outside the payload. No project data moves.

## Schema changes

Additive retrieval metadata and disposable benchmark JSON; stable event identifiers in canonical tables. Rebuild disposable indexes for new chunk boundaries.

## Migration

Follow [V0.17.0 to V0.18.0](../MIGRATIONS.md). Budget selection and structured inputs are optional; exact-only matching intentionally becomes stricter.

## Validation

Baseline: 198 tests. Candidate: 219 passing tests, including 21 new cases. The 12 synthetic benchmark cases preserve all labeled required/useful context with no forbidden hits. Real task outcomes remain unknown. Seven alternating local comparisons on Windows/Python 3.14.6 produce identical graph structures: median graph reconstruction 180.498 to 142.005 ms with an empty process cache and 164.578 to 139.762 ms with a warm process cache. These are local measurements, not a universal speedup or model-token claim.

## Language-variant parity and review evidence

Four independent language variants require AI-assisted delta review, machine parity and installed checks before publication. No independent native-speaker review is claimed.

## Clean assets and package contents

Four language ZIPs and SHA256SUMS.txt; contained installation layout; no repository state, CI workflow, adaptive state or benchmark outputs in payloads.

## Checksums

Pending final asset generation.

## Downstream preservation rules

Preserve populated profiles, application plans, wiki knowledge and all project records.

## Known gaps

[Real-task evaluation](https://github.com/Sistema2D/FrameCode-VibeWork/issues/55), [reversible learning](https://github.com/Sistema2D/FrameCode-VibeWork/issues/56) and [guarded adaptive assist](https://github.com/Sistema2D/FrameCode-VibeWork/issues/57) remain tracked follow-up work. File hints do not replace semantic event declaration. Token estimates are not model usage.

## Rollback

Omit new optional flags or reinstall V0.17.0 by ownership and rebuild indexes. Disable repository CI by reverting its workflow. Preserve project records.

## Publication evidence

User explicitly authorized implementation, issue creation, README update and release publication. Publication evidence is recorded after GitHub confirms the release.
