# FCVW V0.17.0

## Summary

Optional connectome-inspired structural scoring can now be evaluated in shadow
mode while preserving all delivered retrieval results and mandatory paths.

## Related framework plans

- [Connectome shadow routing](../Plans/completed/P2-R4-2026-09-16-connectome-shadow-routing.md).

## Framework surfaces added

`adaptive_router_fcvw.py`, `test_adaptive_routing.py` and
[ADR-0006](../decisions/ADR-0006-adaptive-context-routing.md).

## Framework surfaces changed

Retriever CLI, AI, schema, token, test, context and migration contracts; inventories.

## Framework surfaces removed

None.

## Ownership and path changes

New tools are framework-owned and installed under `FCVW/tools/`. No project data moves.

## Schema changes

Additive disposable structural, shadow and analysis JSON contracts; no existing
Markdown schema changes. No learned state or feedback store.

## Migration

Follow [V0.16.0 to V0.17.0](../MIGRATIONS.md). The feature is disabled by default.

## Validation

Baseline: 178 tests. Source and installed suites: 198 tests, including 20 new
boundary tests. Both clean-template validators report zero findings. Eight query
families preserve V0.16.0 results on the same index. Shadow adds approximately
154–161 ms per query in this Windows/Python 3.14.6 measurement; default mode adds
no graph build. No quality improvement or token saving is claimed.

## Language-variant parity and review evidence

Four independent variants retain prior reviewed prose and adapt changed content.
AI-assisted delta review and deterministic parity are recorded per variant.

if full rollback is required, preserving project records.
