# FCVW V0.21.0 — ready

## Summary

Adopts five data practices from the FlyWire connectome projects (`seung-lab/FlyConnectome`, `flyconnectome/flywire_annotations`): read only the routed sections, anchor to sections instead of whole files, name the successor of a moved or removed link target, keep inferred and verified knowledge apart, and date every frontmatter field. It also carries the shorter root README of the canceled [V0.20.1](V0.20.1.md). The last published baseline is [V0.20.0](V0.20.0.md); this record is the ready candidate built from content revision `3a0a7393e98878dc16856fa7f938fc2f64ed01b8`.
