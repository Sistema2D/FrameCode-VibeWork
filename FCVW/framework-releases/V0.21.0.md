# FCVW V0.21.0 — in preparation

## Summary

Adopts five data practices from the FlyWire connectome projects (`seung-lab/FlyConnectome`, `flyconnectome/flywire_annotations`): read only the routed sections, anchor to sections instead of whole files, name the successor of a moved or removed link target, keep inferred and verified knowledge apart, and date every frontmatter field. It also carries the shorter root README of the canceled [V0.20.1](V0.20.1.md). The published baseline remains [V0.20.0](V0.20.0.md).

## Framework surfaces added

- `retrieve_context.py` route output: `ranges` (first-read line ranges per routed long document) and `context_bytes`.
- `validate_fcvw.py`: rule `markdown-anchor`, successor hints on `markdown-link`, and `--fix-moved-links`.
- `knowledge_graph_fcvw.py --digest PATH[#anchor]`.
- Optional wiki fields `evidence_method` and `verified_by`; `#anchor` in a Markdown `source_path`.
