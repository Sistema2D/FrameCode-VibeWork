# FCVW V0.22.0 — ready

## Summary

Adds an optional, read-only MCP server so any MCP-capable agent harness can call FCVW checks instead of only reading about them. FCVW stays a governance layer, not a harness ([ADR-0013](../decisions/ADR-0013-optional-mcp-server.md)). The last published baseline is [V0.21.0](V0.21.0.md); this record is the ready candidate built from content revision `092462d5393106a7747ea5b65e39ab6385d3d534`.

`AI.md` (optional MCP server section), `FCVW/README.md` pointer, `MIGRATIONS.md`.
