# FCVW V0.22.0 — in preparation

## Summary

Adds an optional, read-only MCP server so any MCP-capable agent harness can call FCVW checks instead of only reading about them. FCVW stays a governance layer, not a harness ([ADR-0013](../decisions/ADR-0013-optional-mcp-server.md)). The published baseline remains [V0.21.0](V0.21.0.md).

- [Fixes from the first MCP field test](../Plans/completed/P3-R2-2026-09-30-mcp-field-test-fixes.md).
- [V0.22.0 publication](../Plans/in_progress/P2-R3-2026-09-30-v0220-publication.md).

## Framework surfaces added

- `tools/mcp_server_fcvw.py` with `fcvw_routes`, `fcvw_read_sections`, `fcvw_validate`, `fcvw_next_plan` and `fcvw_digest`; `tools/test_mcp_server_fcvw.py`.
- [ADR-0013](../decisions/ADR-0013-optional-mcp-server.md).

## Framework surfaces changed

`AI.md` (optional MCP server section), `FCVW/README.md` pointer, `MIGRATIONS.md`. After a field test: `fcvw_routes` lists accepted sessions and events, nested sections are returned once, routes add `APP_RULES.md` for application changes in projects whose rules are `complete` (`CONTEXT_MAP.md`), and the `PROJECT.md` template no longer names a framework version.
