# FCVW V0.22.0 — published

## Summary

Adds an optional, read-only MCP server so any MCP-capable agent harness can call FCVW checks instead of only reading about them. FCVW stays a governance layer, not a harness ([ADR-0013](../decisions/ADR-0013-optional-mcp-server.md)). Published from the ready revision `bd9a4c82bcd27ca6fa5739f36cf6f04ec42deb82`; the reviewed content baseline is `092462d5393106a7747ea5b65e39ab6385d3d534`.

## Framework surfaces changed

`AI.md` (optional MCP server section), `FCVW/README.md` pointer, `MIGRATIONS.md`. After a field test: `fcvw_routes` lists accepted sessions and events, nested sections are returned once, routes add `APP_RULES.md` for application changes in projects whose rules are `complete` (`CONTEXT_MAP.md`), and the `PROJECT.md` template no longer names a framework version.
