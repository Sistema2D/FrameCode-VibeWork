# FCVW V0.23.0 — ready

## Summary

Adds opt-in hooks for Claude Code and Codex that turn three FCVW rules into checks: session start status, a plan before any versioned edit, and validation before the agent stops ([ADR-0014](../decisions/ADR-0014-optional-harness-hooks.md)). The `fcvw/automation@1` contract is their switch: they act only while an active contract declares them, and the validator checks contract and harness configuration against each other. The last published baseline is [V0.22.0](V0.22.0.md); this record is the ready candidate built from content revision `d7f481d6e0cb95300d99d96a0e3639f16130e61f`.
