# FCVW V0.24.0 — ready

## Summary

Release name: *Half-life release*. The framework has reached its half-life: what changes from here on is less than what has already settled. The last published baseline is [V0.23.0](V0.23.0.md); this record is the ready candidate built from content revision `2403f1520c6c029583e514c0f98daadf6bc32dc3`.

A validation signal that separates new defects from known debt, and a closeout that means "decided" ([ADR-0015](../decisions/ADR-0015-validation-signal-and-proportional-gates.md)). Every change answers a failure measured while using FCVW on a real application: the validator now infers the profile, generates a stable legacy baseline and fails only on new findings; the graph reads one git-aware inventory and reports generation and validation separately; a completed plan has no undecided checklist item and a deferred criterion is carried by its target; gates are selected from the surfaces a diff touches; a requested removal includes sanitizing its code. On the measured project the default run went from 34,461 errors under the wrong profile to 2,921 under the right one, in 26 s instead of 70 s.
