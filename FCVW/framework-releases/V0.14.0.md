# FCVW V0.14.0

## Summary

Local release candidate implementing the governance and tooling approved from open issues #42 through #48. The automated and adversarial corrections pass locally; the candidate remains blocked until four independently reviewed language-specific empty-template variants, an immutable source revision, clean archives, and source-bound checksums are complete. No multilingual source or runtime filesystem is planned.

This record does not claim a GitHub tag, Release, clean language-specific asset, or remote issue completion.

## Framework surfaces added

- [`APP_RULES.md`](../APP_RULES.md) and briefing/instantiation routing.
- Pending and in-progress [`QUEUE.md`](../Plans/README.md) contracts, validation, and recommendation CLI.
- Portable frontmatter parser, document-graph builder, queue validator, language-release validator, section indexer, and BM25 retriever under `tools/`.
- Deterministic release packager with archive-manifest inspection, exact candidate/approved review boundaries, and external SHA-256 generation.
- Generated [`DOCUMENT_GRAPH.md`](../DOCUMENT_GRAPH.md) with entrypoint reachability, backlinks, broken-target checks, and generated-source relationships.
- Formal audit, language-review, and wiki-record templates that require preserved identity plus portable links to authoritative sources.
- ADRs for [proportionality/contextual monolith gates](../decisions/ADR-0003-proportionality-and-contextual-anti-monolith-gates.md) and [language-specific clean release artifacts](../decisions/ADR-0004-multilingual-source-and-release-model.md).

## Framework surfaces changed

- Planning, schemas, ownership, context routing, audit, governance gates, tests, release, versioning, migration, filesystem, AI, application documentation, and instantiation policies.
- `anti-monolith-guard` and `code-hygiene-refactor` advanced to `1.2.0` through the self-improvement gate.
- Application and framework release templates now share GitHub-oriented assets, checksums, migration, validation, rollback, and publication-evidence sections.
- Troubleshooting records now have a typed, scoped, source-linked contract; Markdown fence and source-relative link validation no longer accept examples or absolute paths as real relationships.
- Retrieval now fails when mandatory context is absent, assigns unique accent-normalized chunk IDs, and never infers an undeclared framework language.
- Release validation binds checksums to exact language assets, rejects repository/editor state and non-Markdown drift, and enforces content-versus-publication lifecycle revisions.
