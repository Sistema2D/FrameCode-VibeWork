# FCVW V0.19.1 — canceled, folded into V0.20.0

## Summary

Canceled before publication: the maintainer deferred publication until phase 2 ended, so these changes ship in [V0.20.0](V0.20.0.md) and no V0.19.1 asset or tag will exist.

Phase 1 (integrity) of the source-only maintainer backlog (`TODO.md` at the source repository root, not installed): the upgrade no longer overwrites unverifiable local edits, validator loopholes are closed, and project profile edits no longer load the framework policy route.
