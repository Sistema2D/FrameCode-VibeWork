🔒 Fix XSS vulnerability in translation rendering

🎯 **What:**
Fixed a potential Cross-Site Scripting (XSS) vulnerability in `FCVW/docs/index.html` where translation keys were being rendered using `innerHTML`.

⚠️ **Risk:**
Using `innerHTML` could allow malicious scripts embedded in the translation data to be executed within the user's browser context.

🛡️ **Solution:**
Replaced `innerHTML` with `textContent` for translation rendering, effectively mitigating the XSS risk without altering expected functionality.
