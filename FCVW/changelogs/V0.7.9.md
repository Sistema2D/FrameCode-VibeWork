## Justifications

- GitHub Pages/public documentation is moving out of this repository.
- Keeping `FCVW/docs/` would contradict the new physical baseline.
- The root Node/Jest files had no remaining target after removing both documentation site artifacts.
- `FCVW/pr_description.txt` was an obsolete transient artifact that referenced the removed documentation site.

## Affected Files

- Framework documentation, governance metadata, release rules, audit checklist, filesystem tree, changelog records, and wiki session records.

## Functional Impact

- No runtime product behavior changes.
- The framework no longer ships a local HTML documentation page.

## Visual Impact

- The removed documentation page is no longer available from this repository.

## Technical Impact

- The framework root no longer contains Node package files or Jest tests.
- `npm test` is no longer an applicable validation command for the framework baseline.
- Public site publication must be handled in another repository or external deployment pipeline.

## Evaluated Risks and Regressions

- Historical plans, changelogs, audits, and old session syntheses may still mention removed documentation paths as historical evidence.
- Automated tests tied to the removed site are intentionally removed rather than repointed.
- The local checkout has no `.git` metadata, so commit, diff, and tag validation cannot be performed locally.
