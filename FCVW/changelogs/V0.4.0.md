## Release Status

`published`

## Release Type

## Summary

- Promoted framework to a **Pure Markdown Instruction Model** (ADR-0001), deprecating environment script dependencies.
- Discontinued and physically deleted the `mockups/` folder. All visual calibration, layout guidelines, and component requirements are now natively consolidated inside a highly robust `DESIGN.md` file.
- Discontinued and physically deleted the `governance/scripts/sync-filesystem.ps1` script. The visual layout tree is now declared and verified manually by the agent inside `FILESYSTEM.md` and `README.md` to guarantee 100% environment portability.
- Created `decisions/ADR-0001-pure-markdown-over-automation-scripts.md` documenting the architectural pivot context, alternatives, and benefits.
- Pruned script execution checklists and mockups descriptions from `AGENTS.md`.
- Bumped framework version to `V0.4.0` in `MANIFEST.md` and `STACK.md`.
