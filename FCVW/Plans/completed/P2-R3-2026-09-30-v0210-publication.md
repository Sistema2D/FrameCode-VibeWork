# V0.21.0 publication

## Description

Publish V0.21.0 (connectome data practices and the shorter root README) as four language-specific clean templates. The maintainer authorized publication after merging the feature.

## Justification and objective

Installed projects receive nothing until the release is published. The release contract requires an immutable content baseline, four reviewed language variants with machine and structure parity, deterministic assets with checksums, a ready commit and publication evidence.

## Scope

### Included

1. Content-baseline commit, including alternatives written in each release language (`Um de:`, `Uno de:`, `Eines von:`) for the selective-loading table.
2. `pt-BR`, `es` and `de` variants built from the published V0.20.0 translations (and the V0.19.0 translations for older ADRs), with AI-assisted translation of new text; in-page anchors retargeted to translated headings; one approved `LANGUAGE_REVIEW.md` per variant.
3. `locale_fcvw.py --require-complete`, packaging, `SHA256SUMS.txt`, archive verification.
4. Ready commit: release record and `FRAMEWORK_LOCK.md` set to `ready`.
5. Tag, GitHub Release and post-publication evidence, as far as the session's permissions allow.

### Excluded

Framework behaviour changes beyond the language-neutral alternatives marker.

## Affected files or boundaries

`tools/context_routing_fcvw.py`, `tools/test_section_anchors.py`, `FCVW/framework-releases/V0.21.0.md`, `FCVW/FRAMEWORK_LOCK.md`, root `README.md` version surfaces; external staging and assets outside the repository.

## Implementation plan

Follow the framework release steps of `RELEASE.md` in order.

## Proportionality gate

- Real problem: an unpublished release reaches no project; translated tables must stay machine-readable.
- Existing solutions reused: `locale_fcvw.py`, `package_release_fcvw.py`, `verify_release_fcvw.py`, published translations.
- New code: one tuple of localized prefixes and its test.

## Acceptance criteria

- [x] The locale gate passes for all four variants against the external source export.

- [x] The release record and lock agree on the published state only after real publication.
