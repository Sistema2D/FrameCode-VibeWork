# V0.22.0 publication

## Description

Publish V0.22.0 (optional read-only MCP server and its field-test fixes) as four language-specific clean templates. The maintainer authorized publication after merging the fixes.

## Justification and objective

Installed projects receive the MCP server only through a published release, which requires a content baseline, four reviewed variants with machine and structure parity, deterministic assets with checksums, a ready commit and publication evidence.

## Scope

### Included

1. Content-baseline commit (this plan).
2. `pt-BR`, `es` and `de` variants built from the V0.21.0 release staging, with AI-assisted translation of changed lines and of ADR-0013; anchors retargeted to translated headings; one approved `LANGUAGE_REVIEW.md` per variant.
3. `locale_fcvw.py --require-complete`, packaging, `SHA256SUMS.txt`, archive verification.
4. Ready commit; tag and GitHub Release by the maintainer; post-publication evidence.

### Excluded

Framework behaviour changes.

## Affected files or boundaries

`FCVW/framework-releases/V0.22.0.md`, `FCVW/FRAMEWORK_LOCK.md`, shipped `FCVW/README.md` and root `README.md` version surfaces; external staging and assets outside the repository.

## Implementation plan

Follow the framework release steps of `RELEASE.md` in order.

## Proportionality gate

Not applicable — no new code; existing release tooling and translations are reused.

## Acceptance criteria

- [ ] The locale gate passes for all four variants against the external source export.
- [ ] Four ZIPs and `SHA256SUMS.txt` are built and each installed payload passes verification.
- [ ] The release record and lock agree on the published state only after real publication.
