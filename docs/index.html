O que é

Um framework de governança assistida por IA focado em rastreabilidade, arquitetura de memória técnica e automação de fluxos de decisão técnica. Projetado para ambientes de alta conformidade e desenvolvimento escalável.

cancel

O que não é

Não é uma ferramenta de chat genérica, nem um sistema de gestão de projetos tradicional (Jira/Trello). Não substitui a validação humana final, mas atua como o sistema nervoso central da lógica arquitetural.

1.2 Problema & Solução

Cenário Comum

Dívida de Contexto

Decisões técnicas perdidas em threads de Slack ou reuniões sem ata.

arrow_forward Memória Técnica Centralizada
Cenário Comum

Inconsistência de Padrão

Cada squad implementa arquiteturas de forma divergente sem um guia vivo.

arrow_forward AICC & ASE Enforcement
Cenário Comum

Erosão de Requisitos

O código final diverge drasticamente do manifesto original do projeto.

arrow_forward Auditoria Contínua

2.2 Governança por Planos

1
Criação do Draft

Definição do escopo da mudança ou funcionalidade.

2
Análise AICC

A IA valida se o plano fere o Manifesto ou o Context_Map.

3
Human Approval

O Architect/Lead assina o plano digitalmente.

4
Execução Tracked

O código é gerado ou escrito com base no plano estrito.

assignment

Campos Mínimos do Plano

  • [ID] Identificador Único
  • [OBJECTIVE] Meta mensurável
  • [IMPACT] Arquivos e Módulos afetados
  • [TECH_STACK] Ferramentas e libs
  • [VALIDATION_STEPS] Como testar
  • [ROLLBACK] Plano de recuo

2.3 Technical Engine

AICC

Active Intelligence
  • • Verificação em tempo real de conformidade.
  • • Detecção de alucinação arquitetural.
  • • Sugestão automática de padrões de projeto.

ASE

Active Security
  • • Prevenção de vazamento de credenciais em prompts.
  • • Validação de permissões em tempo de execução.
  • • Auditoria imutável de ações de IA.

2.4 Parâmetros LLM Local

Model Range Context Window Uso Recomendado
7B - 8B 8k - 32k Micro-tarefas, autocompletar código, formatação local.
14B - 32B 32k - 128k Geração de planos, revisão de código, mapeamento de integração.
32B - 70B+ 128k+ Design de arquitetura complexa, auditoria entre repositórios.
info TECHNICAL NOTE: Manter 40-60% de buffer de contexto para memória operacional.
warning CONTEXT FLOOR: Mínimo de 16k para projetos com mais de 50 módulos.
