## Summary

- Added a full bilingual (PT-BR and EN) GitHub Pages page that explains the framework end-to-end.
- Implemented language selection on a single static page with responsive layout.
- Consolidated framework operation details (lifecycle, governance, versioning, AI systems, security, validation, and publishing steps).
- Configured GitHub Pages source to publish from branch `main` and folder `/docs`.
- Added explicit local-model sizing guidance (parameters + context window tiers) in GitHub Pages and project Wiki, in PT-BR and EN.
- Updated README lifecycle flowchart to include public documentation publication stage (Wiki + GitHub Pages), keeping it aligned with the current operation.
- Restyled the GitHub Pages documentation using NVIDIA-inspired constraints: monochrome structure, single green accent, and angular geometry.
- Updated GitHub Pages header UX with flag-only language switch (PT-BR, EN, ES, DE) and added support button in the top bar.
- Renamed the page title to "Guia Completo do Framework", removed the old slogan text, and adopted hierarchical topic numbering (`1.`, `1.1`, `2.1`, `3.1`).
- Added Spanish and German content sections with language persistence support in the page script.
- Simplified header badges to keep only `Version: V0.5.0+` on the public page.
- Replaced lifecycle prose sections with framework flowchart blocks and updated quick-start guidance to AGENTS.md-driven AI execution.
- Expanded Spanish and German sections to full topical parity quality with PT-BR/EN across all 12 sections.
- Replaced the GitHub Pages visual system with the Apple `DESIGN.md` reference from `VoltAgent/awesome-design-md`.
- Migrated the page to Apple-style tokens/components: Action Blue interactions, SF Pro typography stack, parchment/light surfaces, pill actions, and restrained elevation.
- Removed the side navigation section to keep the page more direct and content-first.
- Reduced flowchart card widths by approximately 50% on desktop, with responsive full-width fallback on smaller screens.
- Restored the original BuyMeACoffee official image button visual in the header.
- Removed framework-generated development records from `wiki/` so the repository is distributed with a clean knowledge baseline for first-time users.
