# Release V0.5.0 - ASE Expansion and Context Optimization

## Release Date

2026-05-22

## Release Type

`minor`

## Strategic Significance

V0.5.0 consolidates the framework as a fully instantiated governance product by combining identity/scope completion, ASE expansion, wiki knowledge promotion, and context-loading optimization.

## Key Changes

| Change | Type | Impact |
|---|---|---|
| Placeholder removal in core docs (`MANIFEST.md`, `SCOPE.md`, `STACK.md`) | Documentation hardening | Eliminates ambiguity for new agents/users |
| ASE expansion from 1 to 4 skills | Feature | Adds standardized workflows for git commits, wiki lint, and release execution |
| `CONTEXT_MAP.md` introduction | Feature | Reduces startup context overhead with selective loading map |
| Wiki population (`patterns/`, `decisions/`, `releases/`) | Knowledge promotion | Converts session knowledge into reusable indexed artifacts |
| Session frontmatter normalization (S001-S004, S006) | Consistency fix | Improves parser compatibility and chronological sequencing |
| Global markdown link portability normalization | Maintenance | Removes machine-specific `file:///` dependencies |
