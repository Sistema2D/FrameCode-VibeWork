# Release V0.4.0 — Pure Markdown Instruction Model

## Release Date

2026-05-18 · Published to GitHub

## Release Type

`minor`

## Strategic Significance

V0.4.0 marks the **architectural pivot** of the framework: from a hybrid model (Markdown + scripts) to a **pure Markdown instruction model** (ADR-0001). This decision eliminates cross-platform dependencies, simplifies the repository structure, and leans fully into the declarative strength of LLM agents.

## Key Changes

| Change | Type | Impact |
|---|---|---|
| Removed `mockups/` directory | Deletion | Eliminates visual drift; design rules moved to `DESIGN.md` |
| Removed `sync-filesystem.ps1` | Deletion | Eliminates script permission issues |
| Expanded `DESIGN.md` | Enhancement | Now contains VCM (Visual Calibration Methodology) and VDA (Visual Description Audit) |
| Expanded `FILESYSTEM.md` | Enhancement | Now serves as declarative manual layout ledger |
| Created `ADR-0001` | New document | Formal record of the architectural pivot |
| Simplified `AGENTS.md` | Refinement | Pruned deprecated script references |

## Lessons Learned

- **Pattern confirmed:** Pure Markdown instructions are fully sufficient for complex layout and visual validation tasks when executed by modern LLM agents.
- **ADR value demonstrated:** Documenting the decision formally (ADR-0001) prevents regression in future sessions where a new agent might propose re-introducing scripts.

## Relation to Next Version

V0.5.0 builds on the clean foundation of V0.4.0 by:
- Expanding the ASE with 3 new skills
- Populating the wiki with validated knowledge
- Adding `CONTEXT_MAP.md` for session startup optimization
