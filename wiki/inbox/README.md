# Inbox

Entradas temporárias ainda não processadas pela wiki.

## Regras

- Use esta pasta para capturas, notas rápidas, trechos de conversa, hipóteses iniciais e materiais que ainda precisam ser avaliados.
- Conteúdo nesta pasta não deve ser tratado como conhecimento validado.
- Entradas relevantes devem ser promovidas para a pasta apropriada e registradas em `wiki/log.md`.
